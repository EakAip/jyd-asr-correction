🔌 服务概述

本系统基于 FunASR 实时语音识别服务，通过 WebSocket 长连接进行流式音频传输与识别结果回传，支持三种模式：

  • 2pass — 实时上屏 + 离线二次纠错（推荐，兼顾速度与准确率）
  • online — 纯流式实时识别，低延迟
  • offline — 整段/文件一次性高精度识别
WS ws://188.18.18.106:10095

当前环境仅支持 ws:// 明文连接，默认端口 10095。请统一使用 ws:// 协议前缀调用。

🔄 交互流程

  • 1. 建立连接：客户端与服务端建立 WebSocket 连接。
  • 2. 发送配置：连接成功后，首帧发送一个 JSON 文本帧，声明识别模式、采样率、热词等参数。
  • 3. 发送音频：持续发送 二进制帧（16kHz / 16bit / 单声道 PCM 小端）。
  • 4. 接收结果：服务端以 JSON 文本帧 实时回传识别结果。
  • 5. 结束：发送 is_speaking:false 的 JSON 帧，触发最终识别并 flush 缓冲区。
💡 音频要求：16000 Hz 采样率、16 bit 位深、单声道、PCM 裸流（小端）。麦克风采集的音频需重采样到 16k 后发送。WAV 文件需跳过 44 字节文件头只发 PCM 数据；MP3/FLAC/M4A 等压缩格式可整包发送，由服务端 ffmpeg 解码。
⚠️ 本服务当前仅提供 ws:// 明文接入，暂不支持 wss://。所有客户端请使用 ws:// 前缀连接。

📤 请求参数（首帧 JSON 配置）

连接建立后发送的第一个文本帧，JSON 格式：

字段类型必填说明
modestring必填识别模式：2pass / online / offline
chunk_sizeint[]必填分块配置 [5,10,5]，含义为 [回看块, 当前块, 前看块]，对应 600ms 分片
chunk_intervalint可选分块间隔，默认 10
wav_namestring可选音频标识名，默认 "h5"，用于结果回溯
is_speakingbool必填true=开始/持续说话；false=结束，触发最终识别
itnbool可选逆文本标准化（数字/日期转阿拉伯数字等），默认 false
hotwordsstring可选热词，格式为多行 "词 权重"（每行一个，空格分隔），如 "竞业达 60\nhello world 40\n语音识别 50"
wav_formatstring可选文件模式使用：WAV 填 pcm；其他压缩格式填 others
audio_fsint可选文件模式音频采样率，如 16000

📥 响应参数（识别结果 JSON）

服务端以文本帧持续返回：

字段类型说明
textstring识别文本片段
modestring结果类型：2pass-online（实时）/ 2pass-offline（纠错）/ online / offline
wav_namestring对应请求的音频标识
is_finalbool是否为最后一段结果
timestampstring时间戳（offline/2pass-offline 模式返回），格式 [[start,end],...] 毫秒
stamp_sentsarray句级时间戳数组（如启用）
⚠️ 处理 2pass 结果时：2pass-online 是实时上屏文本，应追加显示；2pass-offline 是纠错后的结果，应替换掉对应的 online 文本，避免重复。

结果 JSON 示例

{
  "mode": "2pass-offline",
  "wav_name": "h5",
  "text": "竞业达科技有限公司",
  "is_final": false,
  "timestamp": "[[0,360],[360,600]]"
}

🌐 浏览器 / 前端 JavaScript

使用原生 WebSocket API，采集麦克风音频重采样为 16k PCM 后发送。

// 1. 建立连接
const ws = new WebSocket("ws://188.18.18.106:10095");
ws.binaryType = "arraybuffer";

// 2. 连接成功后发送配置帧
ws.onopen = () => {
  const config = {
    chunk_size: [5, 10, 5],
    wav_name: "h5",
    is_speaking: true,
    chunk_interval: 10,
    itn: false,
    mode: "2pass",
    hotwords: "竞业达 60\nhello world 40\n语音识别 50"  // 多个热词用 \n 换行，格式：词 权重
  };
  ws.send(JSON.stringify(config));
};

// 3. 接收识别结果
let onlineText = "", offlineText = "";
ws.onmessage = (e) => {
  const msg = JSON.parse(e.data);
  if (msg.mode === "2pass-online") {
    onlineText += msg.text;               // 实时结果追加
  } else if (msg.mode === "2pass-offline") {
    offlineText += msg.text;              // 纠错结果替换
    onlineText = "";
  }
  console.log("识别结果:", offlineText + onlineText);
};

// 4. 采集麦克风 → 重采样 16k → 发送二进制 PCM
async function startMic() {
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  const ctx = new AudioContext({ sampleRate: 16000 });
  const source = ctx.createMediaStreamSource(stream);
  const processor = ctx.createScriptProcessor(4096, 1, 1);
  source.connect(processor);
  processor.connect(ctx.destination);
  processor.onaudioprocess = (ev) => {
    const input = ev.inputBuffer.getChannelData(0);   // Float32 [-1,1]
    const pcm = new Int16Array(input.length);
    for (let i = 0; i < input.length; i++) {
      pcm[i] = Math.max(-1, Math.min(1, input[i])) * 0x7FFF;
    }
    if (ws.readyState === 1) ws.send(pcm.buffer);     // 发送 16bit PCM
  };
}

// 5. 结束识别
function stopMic() {
  ws.send(JSON.stringify({
    chunk_size: [5, 10, 5], wav_name: "h5",
    is_speaking: false, mode: "2pass"
  }));
}
💡 本项目使用 recorder-core.js 完成采集与重采样，参考 main.js 中的 recProcess() 与 wsconnecter.js。

🐍 Python 后端（文件转写示例）

使用 websockets 库。安装：pip install websockets

import asyncio
import json
import wave
import websockets

SERVER = "ws://188.18.18.106:10095"

async def transcribe(wav_path: str):
    async with websockets.connect(SERVER, ping_interval=None) as ws:
        # 1. 读取 WAV，获取采样率与 PCM 数据
        wf = wave.open(wav_path, "rb")
        sample_rate = wf.getframerate()
        pcm_data = wf.readframes(wf.getnframes())   # 已跳过头部的 PCM
        wf.close()

        # 2. 发送配置帧（文件用 offline 模式）
        config = {
            "chunk_size": [5, 10, 5],
            "wav_name": "test",
            "is_speaking": True,
            "chunk_interval": 10,
            "itn": False,
            "mode": "offline",
            "wav_format": "pcm",
            "audio_fs": sample_rate,
            "hotwords": "竞业达 60\nhello world 40\n语音识别 50",  # 多个热词用 \n 换行
        }
        await ws.send(json.dumps(config))

        # 3. 分块发送 PCM（每块约 10ms * N）
        chunk = 10240
        for i in range(0, len(pcm_data), chunk):
            await ws.send(pcm_data[i:i + chunk])
            await asyncio.sleep(0.005)

        # 4. 发送结束信号
        await ws.send(json.dumps({
            "chunk_size": [5, 10, 5], "wav_name": "test",
            "is_speaking": False, "mode": "offline",
        }))

        # 5. 接收结果
        result = ""
        async for message in ws:
            msg = json.loads(message)
            result += msg.get("text", "")
            print("片段:", msg.get("text"), "| final:", msg.get("is_final"))
            if msg.get("is_final"):
                break
        print("\n最终结果:", result)

if __name__ == "__main__":
    asyncio.run(transcribe("audio.wav"))
⚠️ 若为 MP3/FLAC 等压缩格式，将 wav_format 设为 "others" 并直接发送整个文件字节，由服务端 ffmpeg 解码。

🤖 Android（Kotlin + OkHttp）

使用 OkHttp 的 WebSocket，配合 AudioRecord 采集 16k PCM。依赖：implementation("com.squareup.okhttp3:okhttp:4.12.0")

import okhttp3.*
import org.json.JSONObject
import android.media.*

class AsrClient {
    private val client = OkHttpClient.Builder()
        .pingInterval(0, java.util.concurrent.TimeUnit.SECONDS)
        .build()
    private var ws: WebSocket? = null
    @Volatile private var recording = false

    fun connect(url: String = "ws://188.18.18.106:10095") {
        val request = Request.Builder().url(url).build()
        ws = client.newWebSocket(request, object : WebSocketListener() {
            override fun onOpen(webSocket: WebSocket, response: Response) {
                // 发送配置帧
                val config = JSONObject().apply {
                    put("chunk_size", org.json.JSONArray(listOf(5, 10, 5)))
                    put("wav_name", "android")
                    put("is_speaking", true)
                    put("chunk_interval", 10)
                    put("itn", false)
                    put("mode", "2pass")
                    put("hotwords", "竞业达 60\nhello world 40\n语音识别 50")  // 多个热词用 \n 换行
                }
                webSocket.send(config.toString())
                startRecording()
            }
            override fun onMessage(webSocket: WebSocket, text: String) {
                val msg = JSONObject(text)
                val result = msg.optString("text")
                val mode = msg.optString("mode")
                // 2pass-online 追加，2pass-offline 替换
                android.util.Log.d("ASR", "[$mode] $result")
            }
            override fun onFailure(webSocket: WebSocket, t: Throwable, r: Response?) {
                android.util.Log.e("ASR", "error", t)
            }
        })
    }

    // 采集 16k/16bit/单声道 PCM 并发送
    private fun startRecording() {
        val sampleRate = 16000
        val minBuf = AudioRecord.getMinBufferSize(
            sampleRate,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT
        )
        val recorder = AudioRecord(
            MediaRecorder.AudioSource.MIC, sampleRate,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT, minBuf
        )
        recording = true
        recorder.startRecording()
        Thread {
            val buf = ByteArray(1920)   // 约 60ms
            while (recording) {
                val n = recorder.read(buf, 0, buf.size)
                if (n > 0) ws?.send(okio.ByteString.of(buf, 0, n))
            }
            recorder.stop(); recorder.release()
        }.start()
    }

    fun stop() {
        recording = false
        val end = JSONObject().apply {
            put("chunk_size", org.json.JSONArray(listOf(5, 10, 5)))
            put("wav_name", "android")
            put("is_speaking", false)
            put("mode", "2pass")
        }
        ws?.send(end.toString())
    }
}
💡 需在 AndroidManifest.xml 声明 RECORD_AUDIO 与 INTERNET 权限，并在运行时申请麦克风权限。本服务为 ws:// 明文连接，需在 AndroidManifest.xml 中设置 android:usesCleartextTraffic="true"（或在 network-security-config 中允许对应域名的 cleartext），否则 Android 9+ 会拦截明文连接。
